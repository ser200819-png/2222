# Thirteen Flames — мод по мотивам вселенной Лололошки (Forge 1.16.5)

## Как собрать .jar

Вариант без установки чего-либо на компьютер:
1. Создайте репозиторий на GitHub.
2. Загрузите ВСЁ содержимое этой папки в корень репозитория (папки `src` и `.github`, файлы `build.gradle`, `gradle.properties`, `settings.gradle`).
3. Вкладка Actions -> Build Mod Jar -> Run workflow.
4. Через 5-10 минут скачайте jar из секции Artifacts запуска.

Локально: установите JDK 8 и Gradle 7.x, затем `gradle build` — jar появится в `build/libs/`.

## Предметы (вкладка "Тринадцать Огней")

| Предмет | Эффект |
|---|---|
| Молот Монту | добыча руды 3x3x3 одним ударом |
| Перчатки Монту | Спешение II, пока в руке |
| Клык Ронаса | Яд II цели, владелец получает Слабость |
| Щит Ронаса | блок + Сопротивление I в левой руке |
| Лунный Лук Кнефмтити | стрелы призывают молнию |
| Чёрная Роза Кнефмтити | ПКМ по земле: союзный зомби "Павший" (не атакует игроков) |
| Горн Селиасэт | ПКМ: отбрасывает врагов в радиусе 5 блоков |
| Солнце Селиасэт | Ночное зрение, пока в инвентаре |
| Перо Хэтинтэпа | Медленное падение, пока в инвентаре |
| Свиток Правды | ПКМ: подсвечивает сущности в радиусе 16 блоков |
| Меч Путешественника | ПКМ: рывок вперёд |
| Посох Джодаха | ПКМ: телепорт на 12 блоков |
| Маска Междумирца | шлем с Огнеустойчивостью; Shift+ПКМ: телепорт к спавну |
| Маска Лололошки | шлем со Скоростью |
| Шарф Джона (JDH) | нагрудник с Огнеустойчивостью |
| Очки Джона | шлем с Ночным зрением |
| Значок Джона | Удача, пока в инвентаре |

Все предметы имеют рецепты в верстаке (см. `src/main/resources/data/thirteenflames/recipes`).

Текстуры нарисованы с нуля (16x16) — при желании замените PNG в
`src/main/resources/assets/thirteenflames/textures/item/`.
